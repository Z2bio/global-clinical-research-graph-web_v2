# v2.4.0 升级说明

## 本次修复/升级的用户问题

1. 页面右上出现 `viewList / viewSplit / viewMap` 内部 key，而非正常中文按钮。
2. 研究图谱左侧列表/筛选占用固定空间，希望可以收缩。
3. 地图区和结果区比例固定，希望可根据页面自由调整。
4. 地图聚合圆点在不同尺寸下被拉扁，数字视觉不居中。
5. “中国优先 / 全球视野”只改变按钮状态，没有真实改变地图范围。
6. 希望公益展示版进一步加强 ChiCTR、NMPA、WHO ICTRP、国家医学研究登记备案的自动连接能力。

## v2.4 对应修改

### 1. i18n Key 泄漏修复

- 视图按钮保留中文 fallback 文案；
- i18n 翻译函数不再把找不到翻译的 key 直接写进 DOM；
- 根元素本身带 `data-i18n` 时也可正确翻译；
- 自动测试保证页面源代码不出现可见的 `viewList/viewSplit/viewMap`。

### 2. 可收缩筛选栏

新增：

- `filter-collapse-button`
- `filter-expand-rail`

收起后，主工作区自动把宽度让给结果和地图；状态保存在当前浏览器。

### 3. 可拖拽地图比例

新增 `workspace-layout.js`：

- 公示页列表/地图之间可拖动分隔条；
- 完整地图页结果列表/地图之间同样可拖动；
- 支持“一键自适应”；
- 浏览器 resize 时刷新地图尺寸。

### 4. 地图视觉修复

- 集群 Marker 固定正方形尺寸并 `aspect-ratio:1/1`；
- 数字水平/垂直严格居中；
- 使用更克制的渐变、描边和阴影；
- fallback SVG 使用等比例布局，避免点位被压扁。

### 5. 中国/全球视野真正生效

- 中国优先：优先 fit 中国中心；没有中国中心时回到中国默认范围；
- 全球视野：显式设置世界中心和世界缩放级别；
- fallback 坐标预览同样使用不同的中国/全球坐标范围。

### 6. 多来源自动同步增强

- ChiCTR：公开分页 + 增量 + 历史回填；
- NMPA：公开列表 + 年度 CTR 前缀 + seeds + 回填；
- WHO ICTRP：官方/允许导出一次配置后全自动；
- 国家医学研究登记备案：公开门户健康检测 + 官方/授权批量导出一次配置后全自动；
- 不绕过登录、验证码或访问控制。
