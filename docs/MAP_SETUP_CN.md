# v2.2 中国地图接入说明

## 1. 为什么默认使用高德地图

本项目面向中国客户，正式地图展示应优先采用在中国境内提供合规互联网地图服务的供应商。v2.2 的中国地图适配器默认以高德地图 JS API 2.0 为目标实现。

项目不会默认接入 OpenStreetMap/CARTO 等境外底图作为中国生产底图。

## 2. 配置位置

文件：`assets/js/config.js`

```js
map: {
  amapKey: '',
  amapSecurityJsCode: '',
  enableEnglishMapLabels: false
}
```

需要申请高德开放平台 Web端（JS API）Key 和安全密钥 JsCode。

## 3. GitHub Pages 注意

GitHub Pages 是纯静态托管，无法真正把安全密钥隐藏在服务器端。因此：

- Demo/内部验证：可以使用前端 JsCode 配置。
- 正式生产：建议增加受控代理服务，把安全密钥保存在服务端。

## 4. 坐标系

ClinicalTrials.gov 的 `geoPoint` 以标准经纬度信息提供。本项目在高德地图模式下，对中国境内执行中心调用：

```js
AMap.convertFrom(coords, 'gps', callback)
```

将 GPS/WGS84 坐标转换成高德使用的坐标体系后再绘制，避免中国境内点位与底图发生明显偏移。

一次转换最多 40 对坐标，代码已按批次处理。

## 5. 中英文地图

v2.2 的网站 UI 本身可独立切换中文/英文。

高德底图英文标注属于多语言地图能力，可能需要单独开通权限。配置：

```js
enableEnglishMapLabels: true
```

只有在对应高德 Key 已具备相关权限时再开启。否则英文 UI 下底图可继续保持中文，而应用按钮、筛选、侧栏使用英文。

## 6. 地图展示边界

- 仅展示公开临床研究登记中的执行中心位置。
- 不收集用户实时定位。
- 不根据患者位置做“适合参加哪个试验”的自动推荐。
- 不自行修改行政边界或国家版图表达。
- 正式地图中不要隐藏地图服务商 Logo、版权信息或依法要求展示的信息。

## 7. 无 Key 时的行为

如果 `amapKey` 为空，系统不会报白屏，而是使用“坐标分布预览”：

- 可以看到经纬度点的大致全球分布；
- 可以点击点查看关联医院/研究；
- 不是地图底图；
- 页面会明确提示需要配置高德 Key。
