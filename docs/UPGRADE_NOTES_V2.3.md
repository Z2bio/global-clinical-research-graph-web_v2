# v2.3.0 升级说明

## 本版本解决的三个实际问题

### 1. “勾选了 5 个来源，为什么只有 1 个数据源？”

原因：v2.2 的来源复选框只是 **数据筛选 UI**，并不等同于网络连接器。

v2.3 新增真正的数据同步层：

- CTG：浏览器访问时实时 API；
- ChiCTR：GitHub Actions 每日公开最新页增量；
- NMPA：GitHub Actions 每日公开查询 + CTR seed；
- WHO ICTRP：配置授权/官方导出 Feed 后自动同步；
- 国家医学研究备案：配置公开/授权导出 Feed 后自动同步。

页面同时读取 `data/source-status.json`，让“实时 / 已同步 / 部分覆盖 / 待授权 / 待数据 / 同步异常”成为真实状态，而不是装饰标签。

### 2. 左侧没有明显的上下滚动拉条

v2.3 新增自定义滚动控件：

- 始终可见轨道；
- 可拖拽 thumb；
- 上下按钮；
- 轨道点击；
- 键盘导航；
- 不依赖 macOS 的“自动隐藏滚动条”系统设置。

### 3. 地图没有直接出现在公示页面

v2.3 把地图直接嵌入主工作区，桌面端首次打开默认 `列表 + 地图`。

为了避免继承旧版本浏览器里曾保存的“列表模式”，v2.3 使用新的视图偏好 key，首次升级时会重新采用 split 默认值。

## 兼容性

- 继续支持 GitHub Pages；
- 继续支持手机筛选抽屉；
- 保留完整“研究图谱”独立页面；
- 保留 v2.1 的多源统一研究模型与严谨分类边界；
- Service Worker 缓存版本升级为 v2.3.0。
